# SISTECH 2026 - Mini-Bootcamp MLOps

Repository ini berisi kumpulan **Hands-On Task** dari Mini-Bootcamp **Machine Learning Operations (MLOps)** SISTECH 2026. Setiap task merepresentasikan satu tahapan dalam membangun sistem machine learning secara end-to-end, mulai dari persiapan data, feature engineering, pemodelan, hingga tahap-tahap lain yang menjadi bagian dari alur kerja MLOps.

---

## Daftar Task

| Task | Topik | Deskripsi Singkat |
|---|---|---|
| Task 1 | Data Foundation & Feature Engineering | Exploratory Data Analysis, Feature Engineering (temporal & spasial), Pseudo-Labeling (severity + space-time decay) |
| Task 2 | Modelling | Baseline & Feature Vector Assembly, Model Training & Evaluation, Continual Learning (drift detection, checkpoint retraining, versioning), Model registry/versioning |
